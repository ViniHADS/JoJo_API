Conhecer a JojoAPI ↗

A JojoAPI, criada por ItzSylex, reúne informações sobre personagens e Stands de JoJo, como nomes, tipos de Stand, características dos usuários e links de imagens. O projeto documenta consultas por parte da obra e filtros por características dos personagens.

Como o serviço original está indisponível, baixei o arquivo data.json do repositório e incluí uma seleção dos registros em arquivos JSON locais. O JavaScript carrega esses arquivos com a Fetch API, pelo servidor local na minha máquina. Assim, a página utiliza uma cópia dos dados, sem depender do servidor original.

Para deixar a seleção do meu jeito, acrescentei Gyro manualmente e adaptei Jonathan e Joseph para suas fases como usuários de Hamon. Eles já aparecem na base original, mas associados a registros de Stands. Mantive os dados de origem separados dessas adaptações.

Embora o README da JojoAPI mencione três partes, o arquivo baixado também contém Stone Ocean. Gyro, de Steel Ball Run, não está nessa base.
